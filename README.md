# Rezka TV

**English summary.** Rezka TV is an unofficial Android TV client for the rezka (HDrezka) video site, built for a weak
TV (TCL, Android 9, 32-bit ARM, 4× Cortex-A53, 1.4 GB RAM). Instead of the site's web player in a WebView it uses
native ExoPlayer (Media3) playback and offers a TV interface in the style of big streaming services: a navigation rail,
a billboard, rows of posters, a title page, an episode panel, scrubbing previews, «next episode» autoplay and sign-in
by scanning a QR code with a phone. The APK is ≈3.7 MB. The UI is in Russian. You need your own rezka account; the app
does not host or distribute any content.

---

Неофициальный клиент rezka (HDrezka) для Android TV, сделанный для слабого телевизора: вместо плеера сайта в WebView —

## Что умеет

- Главная: меню слева (раскрывается при фокусе), большая обложка выбранного тайтла с описанием и рейтингами,
  ряды «Продолжить просмотр» (с полоской прогресса), «Закладки», «Новинки», популярное.
- Разделы «Сериалы», «Фильмы», «Мультфильмы», «Аниме», «Закладки» — сетки постеров с подгрузкой страниц и сортировкой.
- «Рейтинг» — до 500 лучших по IMDb фильмов, сериалов, мультфильмов и аниме, которые есть на rezka (место, оценка
  и число голосов на постере), фильтры по десятилетию и жанру, «Скрыть просмотренные».
- «Оскар» — победители и номинанты по годам («Лучший фильм», «Анимационный», «Международный»), прогресс
  «Посмотрено 37 из 590» и по каждой церемонии; фильмы, которых нет на rezka, показаны серыми и в прогресс не входят.
- Отметка «Просмотрено»: ставится сама, когда фильм досмотрен до 90 % в нашем плеере, вручную — долгим нажатием OK
  на постере в «Рейтинге» и «Оскаре» или кнопкой на странице фильма. Тайтлы из «Досмотреть» помечены как начатые.
- Страница тайтла: «Продолжить · S2:E7 · осталось 23 мин», «Следующая: S2:E8», «Сезоны и серии», выбор озвучки.
- Поиск со своей экранной клавиатурой (русская, английская, цифры) — системная клавиатура телевизора неудобна с пульта.
- Плеер (ExoPlayer + leanback):
  - OK — пауза, ←/→ — перемотка с превью кадров (удержание ускоряет), Назад закрывает панели, потом плеер;
  - кнопки «Предыдущая серия» / «Следующая серия», панели «Серии», «Озвучка», «Качество» (Авто, 360p … 1080p Ultra), «Субтитры»;
  - в конце серии — «Следующая серия через 10 с» с автозапуском (отключается в настройках);
  - прогресс уходит на сайт, поэтому «Досмотреть» на rezka и в приложении совпадает.
- Вход в аккаунт с телефона по QR-коду (см. ниже) или на самом телевизоре через сайт.
- Настройки: качество по умолчанию, автозапуск следующей серии, шаг перемотки, облегчённый режим
  (без большой обложки и с меньшим числом рядов), зеркало сайта, «Войти» (QR-код) и «Выйти из аккаунта», очистка кэша.
- Режим «Сайт» — сайт целиком в WebView как запасной вариант.

**Производительность** — главное требование для слабого ТВ: разобранные страницы кэшируются на диске и показываются
сразу, сеть только обновляет их; HTML разбирается в фоне и только нужными кусками; постеры в RGB_565;
WebView не запускается в родных экранах (свои cookies).

## Замеры

TCL на Android TV 9: Realtek RTD284x, 4× Cortex-A53 900 МГц, 1,4 ГБ RAM, 32-битный ARM, интерфейс 1280×720.
Release-сборка после `cmd package compile -m speed`, домашний Wi-Fi.

| Что | Сколько |
|---|---|
| Размер APK | 3,7 МБ |
| Холодный старт до первого кадра (`am start -W`, 5 запусков) | 815–828 мс |
| Ряды главной из кэша | ≈0,39 с после старта процесса |
| Свежие ряды с сайта (самый медленный запрос) | 1,2–1,5 с |
| Прокрутка рядов (`dumpsys gfxinfo`, 1174 кадра) | 50 % кадров ≤ 10 мс, 90 % ≤ 18 мс, 99 % ≤ 34 мс |
| Память на главной / во время 1080p (PSS) | ≈56 МБ / ≈81 МБ |
| CPU во время 1080p | приложение ≈35–45 % одного ядра, вся система ≈35 % из 4 ядер |
| От OK до картинки | ≈4,3 с: страница и ссылка на поток ≈1 с, первый сегмент с CDN ≈3 с |

Видео декодирует аппаратный декодер Realtek; приложение только качает поток и рисует интерфейс.

## Требования

- Android TV 9 (API 28) и новее.
- Аккаунт rezka (для «Досмотреть», закладок и премиум-качества).

## Сборка и установка

Нужны JDK 17+ и Android SDK (platform 36).

```sh
./gradlew testDebugUnitTest assembleRelease
adb connect <ip-телевизора>:5555
adb install -r app/build/outputs/apk/release/app-release.apk
# Заметно ускоряет запуск и разбор страниц на слабом процессоре (повторять после каждой установки):
adb shell cmd package compile -m speed -f dev.alaev.rezkatv
```

Отладочная сборка (`assembleDebug`) на таком телевизоре работает в 2–3 раза медленнее.

**Подпись release-сборки.** Если в корне репозитория лежит `keystore.properties`, release подписывается ключом из него
(сам файл, как и `*.jks` / `*.keystore`, в `.gitignore`); `storeFile` — путь к хранилищу ключей от корня репозитория:

```properties
storeFile=rezka-tv-release.jks
storePassword=…
keyAlias=rezka-tv
keyPassword=…
```

Создать ключ: `keytool -genkeypair -keystore rezka-tv-release.jks -alias rezka-tv -keyalg RSA -keysize 2048 -validity 10000`.
Без `keystore.properties` release подписывается отладочным ключом (`~/.android/debug.keystore` —
у каждого компьютера свой). Обновление ставится поверх установленного (`adb install -r`) только с тем же ключом;
иначе приложение придётся удалить, а с ним пропадут вход в rezka, прогресс и настройки. Поэтому ключ и пароли сохраните — без них следующую версию поверх не поставить.

Приложение появляется в списке приложений телевизора как «Rezka TV»; из консоли:
`adb shell am start -n dev.alaev.rezkatv/.rezka.BrowseActivity`.

## Вход по QR-коду

1. Настройки → «Войти» (экран входа открывается и сам, если сайт просит войти; можно войти и в другой аккаунт).
2. Наведите камеру телефона на QR-код. Телефон должен быть в той же Wi-Fi сети, что и телевизор.
3. На открывшейся странице менеджер паролей телефона подставит email и пароль rezka (или введите их) — «Войти».

<img src="docs/screenshots/phone-login.jpg" width="260" alt="Страница входа на телефоне">

Как это устроено. Пока экран открыт, телевизор поднимает маленький HTTP-сервер в локальной сети (порт 8765–8775).
Менеджеры паролей на `http://`-страницах по IP часто не подставляют пароль, поэтому QR ведёт на статичную
HTTPS-страницу [`docs/login/`](docs/login/index.html) на GitHub Pages:

- адрес телевизора, одноразовый 128-битный токен и открытый ключ телевизора (P-256, новый на каждый код) — во
  фрагменте ссылки (после `#`), который браузер на сервер не отправляет: GitHub их не видит;
- страница шифрует email и пароль (ECDH → SHA-256 → AES-GCM, токен — дополнительные данные) и переходит
  на страницу телевизора, передав шифротекст во фрагменте; расшифровать его может только телевизор
  ([`LoginCrypto.kt`](app/src/main/java/dev/alaev/rezkatv/rezka/login/LoginCrypto.kt)), закрытый ключ живёт в его памяти;
- входит сам телевизор (запрос к `/ajax/login/` сайта), пароль никуда не записывается.

Без верного токена сервер отвечает 403. Код действует 10 минут, после 5 неверных паролей нужен «Новый код».
Без интернета на телефоне — ссылка под QR-кодом открывает страницу самого телевизора напрямую. Если телефон
не может подключиться к телевизору (гостевая сеть, изоляция клиентов в роутере) — «Войти на телевизоре».
В форке поменяйте адрес страницы в `LoginCode.PHONE_PAGE` и включите GitHub Pages из папки `docs/`.

## Продолжить после выключения телевизора

- Плеер каждые 10 секунд, а также на паузе, при смене серии и при сворачивании записывает «сеанс»: тайтл, озвучку,
  сезон, серию, позицию — в файл с атомарной записью, так что выдёргивание вилки его не портит. На сайт прогресс
  уходит раз в минуту.
- «Продолжить» (ряд на главной или кнопка на странице тайтла) открывает плеер на той же серии и том же месте,
  даже если телевизор выдернули из розетки.
- Если телевизор «выключили» пультом в режим ожидания, плеер остаётся открытым: после включения он заново берёт
  страницу тайтла с сайта, обновляет поток (ссылки на видео живут несколько часов) и ждёт OK на своём месте.
- Перед продолжением всегда сверяемся с сайтом: если на другом устройстве досмотрели дальше (другая серия или
  озвучка), плеер переходит туда и пишет «Продолжаем с S1:E5 — смотрели на другом устройстве». Сайт хранит только
  озвучку и серию — время просмотра он не отдаёт (проверено: ни страница, ни API плеера, ни «Досмотреть» его не
  содержат), поэтому время берётся своё, если серия та же, иначе серия начинается с начала.
## Для разработчиков

- Логи: `adb logcat -s RezkaTv` — время загрузки и разбора каждой страницы, запуск потока и т. п.
- Юнит-тесты: `./gradlew testDebugUnitTest` (разбор страниц и ответов сайта, серии, прогресс, cookies, кэш, вход,
  «Продолжить после выключения»). Фикстуры в `app/src/test/resources` — маленькие синтетические страницы и ответы,
  не копии сайтов.
- Выход с главной завершает процесс приложения и сразу отдаёт системе память плеера, WebView и постеров.

## Списки «Рейтинг» и «Оскар»

Списки лежат в `app/src/main/assets/lists/` и собираются скриптом на компьютере (Python 3, без сторонних пакетов):

```sh
python3 tools/build_lists.py --cookies rezka-cookies.txt   # потом пересобрать приложение
python3 -m unittest discover -s tools                      # тесты скрипта
```

- `--cookies` — cookies вошедшего аккаунта rezka в формате Netscape (расширение браузера «cookies.txt» или `curl -c`):
  без входа сайт не отдаёт ни поиск, ни страницы.
- «Рейтинг» берётся из [открытых наборов данных IMDb](https://developer.imdb.com/non-commercial-datasets/)
  (фильмы от 25 000 голосов, сериалы от 10 000, анимация от 10 000 и 5 000), места — по взвешенной оценке, как в
  IMDb Top 250. Каждый тайтл ищется на rezka по названию и году (±1), при нескольких похожих — по ссылке на IMDb
  на странице тайтла; раздел (фильмы, сериалы, мультфильмы, аниме) — тот, где тайтл лежит на rezka.
  Данные IMDb нельзя распространять, поэтому `top.json` не попадает в репозиторий и собирается у себя; без него
  раздел пишет «Рейтинг ещё не собран».
- «Оскар» — из [Wikidata](https://www.wikidata.org/) (CC0); пробелы и ошибки Wikidata за последние годы поправлены
  в `tools/oscars_fixes.tsv`. `oscars.json` лежит в репозитории.
- Полная сборка — около двух часов: к rezka не чаще запроса в 2 секунды. Всё скачанное кэшируется в
  `~/.cache/rezka-tv`, поэтому прерванный запуск продолжается с того же места, а повторный идёт без сети (`--offline`).
  Чего не нашлось на rezka — в `~/.cache/rezka-tv/unmatched.tsv`.

## Отказ от ответственности

Это неофициальный клиент, не связанный с rezka/HDrezka. Приложение не размещает, не хранит и не распространяет
видео: оно лишь показывает в удобном для пульта виде то, что сайт отдаёт вашему аккаунту. Нужен собственный
аккаунт rezka (и подписка — для премиум-контента). Соблюдайте правила сайта и законы своей страны.
